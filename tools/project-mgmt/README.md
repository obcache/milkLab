# Project Management Tools

This folder contains neutral workflow tools generated by Reponator.

## Files

- `manifest.json` records the generated scaffold.
- `ledger.js` reads `docs/dev-ledger.md` and can print a commit message from Complete entries.
- `todo.js` lists and appends Markdown planning tasks in `docs/planning/To-do.md`.
- `handoff.js` creates a durable handoff summary under `docs/handoffs/`.
- `version-files.js`, `version-show.js`, `version-sync.js`, and `version-bump.js` keep only the explicit first-party version values aligned. Tests exercise patch/minor/major behavior in temporary copies.
- `commit-release.js` bumps the requested version part, commits, and pushes when a remote exists.

## Common Commands

```powershell
npm run todo
npm run todo:add -- "Write first milestone"
npm run ledger:message
npm run handoff
npm run version:show
npm run commit -- "initial release"
```

Application command wrappers live in `tools/*.cjs`; their public entry points are package.json scripts. `stack-command.js` remains a creation-time scaffold artifact and is not invoked by build, test, package, or deploy checks. Manifest `files` hashes describe the original seed, while `implementation` describes the actual application layout. Commit tooling can push to a configured remote; do not invoke it without an authorized commit/release request.
